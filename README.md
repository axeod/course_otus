# course_otus
# Предсказание предпочтений человека между ответами LLM

Итоговый проект курса OTUS (Machine Learning. Basic).

## Задача

Бинарная классификация: по двум ответам разных языковых моделей
на один и тот же вопрос предсказать, какой из них выберет человек.
Модель использует только формальные признаки текста (длина,
структура, форматирование) и не имеет доступа к содержанию.

## Данные

[Chatbot Arena Human Preference](https://huggingface.co/datasets/lmarena-ai/arena-human-preference-55k) — 57 477 парных сравнений,
после очистки 39 687.

## Результаты

| Модель | train | val | test |
|---|---|---|---|
| Логистическая регрессия | 0.621 | 0.613 | — |
| Дерево решений (без ограничений) | 0.924 | 0.539 | — |
| Дерево решений (max_depth=5) | 0.627 | 0.616 | — |
| Случайный лес (max_depth=6) | 0.633 | 0.618 | **0.626** |

Test ROC-AUC: **0.677**

Основной вывод: 72% объясняющей силы приходится на объём ответа,
28% — на все элементы форматирования вместе взятые.
